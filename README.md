# Phulka Website

Official showcase website for **Phulka: Dhaba Cooking Game**.

- **Live URL on GitHub Pages:** [https://harkirat1892.github.io/phulka-website/](https://harkirat1892.github.io/phulka-website/)
- **Repository:** [https://github.com/harkirat1892/phulka-website](https://github.com/harkirat1892/phulka-website)
- **App Privacy Policy:** [https://harkirat1892.github.io/phulka-privacy/](https://harkirat1892.github.io/phulka-privacy/)

## Contents
- `index.html`: Main landing page with story, gameplay overview, screenshots, and iOS/Android download links.
- `styles.css`: Responsive CSS tailored with warm GT Road dhaba palette.
- `script.js`: Interactive navigation and screenshot lightbox.
- `privacy.html`: Dedicated styled privacy policy page.
- `cozy-cooking-games-ios.html`, `dhaba-cooking-simulator.html`, `desi-cooking-game.html`: long-tail search landing pages (see `docs/store/listing.md`, "Long-tail search pages").
- `sitemap.xml`, `robots.txt`: add new pages to the sitemap and bump `lastmod`.
- `images/`: Game icon, 1024x500 feature graphic banner, and gameplay screenshots.
